Desafios de Programação

Como funciona o site?

1. Escolha a dificuldade Selecione o nível do desafio que deseja fazer.

2. Escolha os conteúdos Selecione os conteúdos de programação em C que você quer praticar.

3. Gere o desafio Clique em "Gerar Desafio". A IA criará um desafio de acordo com a dificuldade e os conteúdos selecionados.

4. Resolva o desafio Leia os requisitos e escreva sua solução em C no editor de código.

5. Execute seu código Use o botão de executar para compilar e testar seu programa.

Dica: Leia todos os requisitos do desafio antes de começar a programar.
